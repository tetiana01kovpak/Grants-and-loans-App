# Grant Compass

A Flutter prototype for Android phones and tablets, iPad, Windows and Mac, for a company developing AI navigation and autonomous docking devices for sailing boats and yachts. The bundled shortlist was researched on 12 November 2026 and is not exhaustive or live. Check official call documents for eligibility, current deadlines and mandatory attachments. Defence topics are included for monitoring and do not imply that a civilian project qualifies. None of these builds has been tested yet.

## Build the Android APK

Install Flutter and the Android SDK using the official Flutter Android setup instructions: https://docs.flutter.dev/platform-integration/android/setup. In this directory run PowerShell:

```powershell
flutter create --platforms=android --org com.example .
Copy-Item android-template/MainActivity.kt android/app/src/main/kotlin/com/example/grant_compass/MainActivity.kt -Force
```

In `android/app/src/main/AndroidManifest.xml`, add these lines directly inside `<manifest>` before `<application>`:

```xml
<uses-permission android:name="android.permission.READ_CALENDAR" />
<uses-permission android:name="android.permission.WRITE_CALENDAR" />
```

Then run:

```powershell
flutter pub get
flutter analyze
flutter build apk --release
```

The same APK is expected to run on compatible Android phones and Android tablets. It is expected at `build/app/outputs/flutter-apk/app-release.apk`. Generated release builds use Flutter's default debug signing until a release signing key is configured; do not use that signing setup for a public store release. An iPad needs a separately built iOS app and cannot install an APK.

## Build the Windows computer version

Install Visual Studio (not just Visual Studio Code) with the **Desktop development with C++** workload, following https://docs.flutter.dev/platform-integration/windows/setup. From the project directory run:

```powershell
flutter create --platforms=windows .
flutter pub get
flutter analyze
flutter build windows --release
```

The Windows release folder is expected under `build/windows/x64/runner/Release`. Keep the executable together with the supporting files and folders in that release folder. The Windows build has not been tested.

## Build for iPad and Mac

A Mac with Flutter and Xcode is required. See https://docs.flutter.dev/platform-integration/ios/setup and https://docs.flutter.dev/platform-integration/macos/setup. Copy this project folder to the Mac, preserving `lib`, `pubspec.yaml` and `apple-template`, then in Terminal run:

```sh
flutter create --platforms=ios,macos --org com.example .
cp apple-template/iOS-AppDelegate.swift ios/Runner/AppDelegate.swift
cp apple-template/macOS-MainFlutterWindow.swift macos/Runner/MainFlutterWindow.swift
cp apple-template/GrantCalendarBridge.swift ios/Runner/GrantCalendarBridge.swift
cp apple-template/GrantCalendarBridge.swift macos/Runner/GrantCalendarBridge.swift
flutter pub get
```

Open `ios/Runner.xcworkspace` in Xcode and add `ios/Runner/GrantCalendarBridge.swift` to the Runner project and Runner target (ensure **Target Membership** is selected). Do the same in `macos/Runner.xcworkspace` for `macos/Runner/GrantCalendarBridge.swift`. Replacing the existing host files above and adding this shared Swift file connects the calendar channel. Keep the target and signing settings generated by Flutter.

For **both** targets, add these keys to the target's Info.plist. You can do this in Xcode's Info tab (or edit `ios/Runner/Info.plist` and `macos/Runner/Info.plist`):

```xml
<key>NSCalendarsWriteOnlyAccessUsageDescription</key>
<string>Grant Compass adds grant deadline reminders to your calendar.</string>
<key>NSCalendarsFullAccessUsageDescription</key>
<string>Grant Compass adds reminders and removes its expired grant reminders.</string>
<key>NSCalendarsUsageDescription</key>
<string>Grant Compass adds grant deadline reminders to your calendar.</string>
```

For the macOS target, enable Calendar under Signing & Capabilities > App Sandbox for both debug and release builds. Apple calendar access needs this entitlement. Configure your own signing team in Xcode. You can test on your own iPad with an Apple Account; distribution has separate Apple requirements.

Then validate and build:

```sh
flutter analyze
flutter build macos --release
flutter run -d <ipad-device-id>
```

Use `flutter devices` to find the connected iPad's device ID. The Mac build is expected at `build/macos/Build/Products/Release/grant_compass.app`. For iPad, Xcode signing and device setup are required; an Android APK cannot be used. These Apple setup instructions and templates are untested and may require adjustments for the installed Flutter and Xcode versions.

## Calendar and limitations

On Android and Apple devices, open the app and tap **Connect calendar**, then grant access. Android uses the first visible writable calendar; Apple uses the default calendar. For each listed deadline or batch, the app adds the deadline event plus separate "30 days left", "21 days left" and "14 days left" events that alert at their own time (this works within Google Calendar's 4-week reminder limit and Outlook's one-reminder-per-event limit). An alert whose time has already passed cannot fire retroactively; calendar apps control notifications and synchronization. On iOS/iPadOS 17 and macOS 14 or newer the Apple template requests full calendar access so it can remove its expired reminders; older Apple systems use the older calendar access permission. If you previously granted write-only access, enable full calendar access for Grant Compass in device settings.

On Windows, **Import calendar reminders** creates a standard `.ics` file in the temporary folder and asks Windows to open it in your default calendar application. Import or save the events in that application. A compatible calendar app and `.ics` association are needed; import and reminder behavior vary by app. This is a manual import, not an automatic connection, and repeating the import may create duplicates. If Windows does not open the file, look for `grant-compass-reminders.ics` in your temporary folder and import it using your calendar app.

On all devices, verify the official deadline and closing time; some calendar event times are approximate, and some dates are evaluation batches. The app does not download updates or monitor new calls in the background. On Android and Apple, opening the app or tapping Connect calendar removes expired reminders that this installation created and can still identify, and updates identifiable future events with the new alert schedule. Edited events, events from previous installations, and Apple reminders created before event IDs were saved may need manual changes or removal. Windows imports must be updated manually. No events are created for unknown dates. Revoke permission through device settings. A reinstallation or use on multiple devices may create duplicates. Calendar integration has not been tested on a device.
